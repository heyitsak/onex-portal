# 🚀 OneX Member Portal

A full-stack member management and service portal built with Next.js 16 (App Router), React 19, Tailwind CSS v4, and TypeScript.

## ✨ Features

- **Authentication System** — Secure registration and login powered by bcrypt password hashing and JWT sessions.
- **Member Dashboard** — Overview of active projects, enrolled services, and profile settings.
- **Support Ticketing Engine** — Submit tickets, track resolution status, and participate in threaded discussions.
- **Service Request Management** — Browse available organizational services and submit project requests.
- **Route Protection & Guards** — Client-side and server-side authentication guards.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **UI**: React 19, Tailwind CSS v4
- **Security**: JWT (`jsonwebtoken`), `bcryptjs`
- **Language**: TypeScript

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/heyitsak/onex-portal.git

# Navigate to project
cd onex-portal

# Install dependencies
npm install

# Run the development server (runs on port 3001)
npm run dev
```
